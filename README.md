# اختبر ذكاءك — V10 PWA (محدثة)

## التعديلات
- مؤقت السؤال الأساسي: 10 ثواني.
- XP: +10 لكل إجابة صحيحة، و-5 لكل إجابة خاطئة.
- Double XP يضاعف XP الإجابات الصحيحة.
- متجر Coins داخل اللعبة: قلب إضافي، Double XP، 50:50، و+5 ثواني.
- باقات Coins: 300/$3.99، 650/$7.99، 1300/$14.99، 2800/$29.99، 5000/$49.99، 11000/$99.99.
- أيقونة thinking_person الجديدة.
- PWA manifest + service worker مع استراتيجية تحديث تمنع تثبيت نسخة قديمة بسهولة.
- الدفع المالي داخل هذه النسخة محاكاة فقط؛ Apple In-App Purchase يحتاج تطبيق iOS أصلي وStoreKit.

## رفعها على GitHub Pages
ارفع الملفات الموجودة داخل هذا المجلد إلى جذر فرع `main` واستبدل الملفات القديمة، ثم افتح Settings → Pages وتأكد أن المصدر `main / (root)`.

## إذا ظهر الإصدار القديم
بعد النشر، افتح الموقع في Safari، أعد تحميل الصفحة، وإذا كان التطبيق مثبتًا على الشاشة الرئيسية احذفه وأضفه من جديد بعد أول فتح للنسخة الجديدة.
