# اختبر ذكاءك V.13.50 PWA

آخر نسخة قبل Firebase.

## التحديثات
- بنك أسئلة 5000 سؤال.
- 15 ثانية لكل سؤال.
- نظام قلوب مجزأ: 3 أجزاء لكل قلب، والخطأ يخصم جزءًا واحدًا.
- 5 قلوب أساسية، والحد الأقصى قابل للرفع حتى 10 من المتجر.
- عند نفاد القلوب تتوقف الجولة، ويستعاد قلب كامل كل 30 دقيقة.
- ثلاث مساعدات: 50:50، +10 ثواني، وتجنب السؤال.
- لكل مساعدة استخدام مجاني يتجدد بعد 24 ساعة.
- المساعدات المشتراة لـ50:50 و+10 ثواني تُحفظ كرصد استخدامات ولا تنتهي بوقت.
- لا يوجد شراء لمساعدة تجنب السؤال.
- XP تراكمي بنظام 500 لكل مستوى.
- PWA وService Worker محدثان إلى V.13.50.
