  **أفا متأكد طالع/ه ؟👀**

  **بتخسر فرصة ربح 250 🪙 Coin**
- لا يتم خصم 250 Coin من الرصيد الحالي للاعب.
- اللاعب يحتفظ بالـCoins التي كسبها من إجابات التحدي قبل الخروج.
- إذا لم يكسب أي Coin يخرج بمكسب 0 Coin.
- بعد الخروج يعتبر التحدي اليومي مستخدمًا حتى اليوم التالي.
- عند وجود Coins مكتسبة تظهر رسالة:
  **ما نطلعك خسران 🪙 معك [عدد الـCoins] Coin**
  **نشوفك بكرة ❤️**
- عند عدم وجود Coins مكتسبة تظهر:
  **نشوفك بكرة ❤️**
