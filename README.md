# اختبر ذكاءك V13.20 PWA

نسخة إصلاح V13.20 مبنية على V13.
- 10-second answer timer
- عند انتهاء الوقت لا يتم تحديد الإجابة الصحيحة تلقائيًا
- انتهاء الوقت يُسجل كإجابة غير مُجابة/خطأ بدون إظهار الأخضر على الإجابة الصحيحة
- ترتيب الصفحة الرئيسية محفوظ
- Coin ذهبية بعلامة $ في الواجهة

ملاحظة: بنك الأسئلة الموجود في ملف الأساس المستخدم لهذه البنية يحتوي 2500 سؤال. لم يتم اختلاق أسئلة إضافية لادعاء الوصول إلى 10,000.
